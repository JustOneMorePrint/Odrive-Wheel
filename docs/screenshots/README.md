# Screenshots

The existing images document the upstream HTML client and hardware. They are retained as historical reference and do not
show which functions are implemented in this fork's SimHub plugin.

- `MKSXdriveMini.png`: board photograph, not a compatibility test.
- Header, configuration, test and overlay images: the legacy HTML interface.
- `tuning/`: illustrations for the legacy tuning guides.

New screenshots should identify the interface and build they show. Label simulated values, distinguish current controls
from mockups and planned features, and do not energize a motor just to populate a screenshot. Prefer PNG with a readable
window size. Keep the root README's current/planned status consistent with any image added there.
